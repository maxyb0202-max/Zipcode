From download to running code in three steps

    
Zipcode installs the compilers for you, so there's nothing to set up by hand.

    

      

        
Install Zipcode

        
Run Zipcode-Setup.exe. It installs for your user account only, so it doesn't need admin rights.

      

      

        
Click Install everything

        
The Setup tab finds what's missing (Python, Java JDK 21, gcc/g++) and installs it with Windows' own winget.

      

      

        
Write and press F5

        
Pick a language, start from an example or a blank file, and run it. Type answers to your program straight into the terminal.

      

    

  


  

    
Everything a first project needs

    
The same editor engine as Visual Studio Code, without the setup.

    

      
EDITOR
Real code editor
Syntax colours, auto-indent, find and replace, and multiple tabs. Saves as you type.

      
RUN
One-key run
Compiles C and C++ automatically and runs Java and Python files directly. Stop a stuck program with one click.

      
SHELL
Built-in terminal
A normal Windows command prompt opened in your project folder, with up-arrow history and copy and paste.

      
PACKAGES
Library manager
Search and install libraries for each language from one window, no commands to remember.

      
EXAMPLES
Ready-made examples
A guessing game, a calculator and times tables in all four languages, ready to run and change.

      
UPDATE
Updates itself
New versions download in the background. Press Restart and you're up to date, with no reinstalling.

Questions

        

          Windows says it "protected your PC". Is that normal?
          
Yes. Zipcode is new and isn't code-signed yet, so SmartScreen shows a warning the first time. Click More info, then Run anyway.

        

        

          Is it really free?
          
Yes. Zipcode is free and open source under the MIT licence.

        

        

          Where are my files saved?
          
In Documents\Zipcode by default. Use Open Folder to work anywhere else.

        

        

          How do I update?
          
Open the Update tab and press Check for updates. Zipcode also checks on its own when it starts. A green dot appears when a new version is ready.

        

        

          How do I uninstall it?
          
Settings, then Apps, then Zipcode, then Uninstall. Your code in Documents\Zipcode is left alone.
