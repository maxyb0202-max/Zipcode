Welcome to CodeBox

Pick a language at the top, then press + New or choose one of the Examples.

Press F5 to run your program. Its output appears in the terminal below, and you can type answers there too.

Installs Python libraries with pip. Type one or more names, e.g. requests or numpy pandas.

Searches Maven Central and downloads the .jar (plus its dependencies) into your project's libs folder. Run picks them up automatically. You can also type group:artifact:version.

Uses vcpkg for C and C++ libraries. After installing a library, add a line like // link: -lfmt at the top of your file so Run links it.

CodeBox needs each language's tools installed on this PC. Click Install for anything missing (uses winget, which ships with Windows 10 and 11).
